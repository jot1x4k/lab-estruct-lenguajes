>**Ejercicio 2: Uso de estructuras condicionales (if, switch).** Escribir un programa que solicite al usuario un número entero. Si el número es par, mostrar un mensaje indicándolo. Si es impar, mostrar otro mensaje. Usar el switch para determinar si el número es positivo, negativo o cero. ¿Cuál es la diferencia entre if-else y switch? ¿Cuándo es más eficiente usar switch en lugar de if-else?

La diferencia principal es que if-else evalua expresiones booleanas complejas y rangos, mientras que switch compara una sola variable o expresion contra multiples valores fijos.

Usar switch es mas eficiente cuando se busca acceder a codigo sin revisar cada condicion anterior. Es mejor cuando se tienen mas de 4 o 5 opciones de valor fijo para una sola variable.
